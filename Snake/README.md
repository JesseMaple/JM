# Snake

学生练习作品——贪吃蛇



#### 游戏玩法

运行游戏后自动开始，通过按键控制贪吃蛇的运动方向，通过吃掉食物“$“获得分数和让身体增长，当蛇头撞击地图边缘或自身身体时贪吃蛇死亡，游戏结束



#### 控制按键

“W/w/↑“控制贪吃蛇向上运动

“S/s/↓”控制贪吃蛇向下运动

“A/a/←”控制贪吃蛇向左运动

“D/d/→”控制贪吃蛇向右运动



“ESC”暂停游戏



当“ESC”暂停游戏时，再次按下“ESC”返回游戏，或按下“Enter”退出游戏



#### 代码结构

该项目将代码分为file\_io、game、input和ui四个模块以尽可能实现解耦，game模块应自带config.h，每个模块间应做到通过个模块API传递信息，以实现更换模块时不必大量更改已有模块
